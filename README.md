# 🚀 ATS Resume Checker

An AI-powered ATS (Applicant Tracking System) Resume Checker that analyzes resumes against job descriptions using Google Gemini AI. It provides an ATS score, keyword analysis, AI-powered suggestions, and resume optimization recommendations to help job seekers improve their chances of getting shortlisted.

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 📝 Paste Job Description
- 🤖 AI-powered Resume Analysis using Google Gemini
- 📊 ATS Match Score Calculation
- 🎯 Match Percentage
- ✅ Matched Keywords Detection
- ❌ Missing Keywords Detection
- 💡 AI-Powered Resume Improvement Suggestions
- 💪 Strengths & Weaknesses Analysis
- 📑 Optimized Professional Summary
- 📋 Detailed Section Analysis
- 📚 Analysis History
- 🗑️ Delete Analysis History
- ⏳ Professional Analysis Progress Loader
- 🌙 Modern Responsive Dark UI
