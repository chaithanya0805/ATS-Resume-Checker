# ATS Resume Checker 🚀

An AI-powered ATS Resume Analyzer that helps job seekers optimize their resumes based on job descriptions.

## 🔥 Features
- Upload resume (PDF)
- Analyze resume with job description
- ATS score calculation
- Keyword matching
- Suggestions for improvement

## 🛠 Tech Stack
- Frontend: React.js
- Backend: Spring Boot
- Database: MySQL

## 📂 Project Structure
- frontend/ → React UI
- backend/ → Spring Boot API

## 🚀 How to Run

### Backend
cd backend
mvn spring-boot:run

### Frontend
cd frontend
npm install
npm start
